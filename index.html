FAQ

عندي Manager نسخة Desktop، ينفع؟

حاليًا البرنامج شغال مع نسخة Server وCloud. دعم الـ Desktop جاي قريب، ولو عاوز تجرّبه معايا ابعتلي.

معنديش Manager، بشتغل على البورتال بس

تبويب مصلحة الضرائب شغال لوحده: كل مبيعاتك ومشترياتك من المنظومة، وتقارير Excel وPDF، وتنزيل كل الفواتير PDF.

لو بعتت فاتورة غلط؟

كل فاتورة بتتراجع قبل الإرسال. ولو حصل، تقدر تلغيها من البرنامج خلال فترة الإلغاء المسموحة، أو تعمل إشعار دائن.

التوكن على جهاز وManager على سيرفر تاني

البرنامج بيتسطّب على الجهاز اللي عليه التوكن، وبيقرأ من Manager اللي على السيرفر عن طريق الشبكة.

برنامج واحد بيشغّل كل الشركات، وكل رقم تسجيل ليه ترخيص لوحده.

I use Manager Desktop edition. Does it work?

Server and Cloud editions are supported today. Desktop support is coming; email me if you'd like to test it.

I don't use Manager, only the ETA portal

The tax portal tab works on its own: all your sales and purchases from ETA, Excel and PDF reports, and bulk PDF download.

What if I submit a wrong invoice?

Every invoice is reviewed before it is sent. If it happens, cancel it from the program within ETA's cancellation window, or issue a credit note.

The token is on one PC and Manager on another server

Install the program on the PC with the token; it reads from your Manager server over the network.

I have more than one company

One program runs them all, with a separate license per tax registration number.

Does it support e-receipts (B2C)?

No, it's for business invoices and notes (e-invoicing) only.

Windows says the program isn't safe

The installer isn't code-signed yet. Click More info, then Run anyway.
